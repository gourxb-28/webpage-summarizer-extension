# [Webpage Summarizer](https://github.com/gourxb-28/webpage-summarizer-extension/tree/main)

**Chat with any webpage.** An AI-powered Chrome extension that lets you ask questions about any webpage, such as articles, blogs, or documentation—using a local RAG pipeline.


## Features

- Extracts full webpage content dynamically, right from the active tab
- Splits large text into context-aware chunks using `RecursiveCharacterTextSplitter`
- Embeds chunks into a vector database using `SentenceTransformer` + `FAISS`
- Uses `Ollama LLaMA 3.2` (via LangChain) as the RAG LLM
- Handles user queries through a `FastAPI`-based RAG pipeline
- Lightweight Chrome Extension front-end for 1-click chatting on any page

## How It Works

1. **Frontend (Chrome Extension)** — Captures the content of the current page and sends it to the FastAPI backend along with the user's query.
2. **Backend (FastAPI + LangChain)**
   - Splits and embeds the page content
   - Stores vectors in a FAISS index
   - Retrieves the most relevant chunks for the query
   - Passes the query + retrieved context to the LLM
3. **LLM Response** — Generated by LLaMA 3.2 via Ollama, sent back to the extension, and displayed in a chat bubble/popup.

## 🛠️ Tech Stack

| Layer        | Technology                                    |
|--------------|-----------------------------------------------|
| Frontend     | HTML, JavaScript (Chrome Extension)           |
| Backend      | Python, FastAPI                               |
| LLM          | Ollama — `LLaMA 3.2`                          |
| RAG Tools    | LangChain, FAISS, SentenceTransformer         |
| Embeddings   | `BAAI/bge-small-en` (Sentence Transformer)    |

## Installation

### Prerequisites

- Python 3.9+
- [Ollama](https://ollama.com/) installed locally with the `llama3.2` model pulled
- Google Chrome

### 1. Clone the repository

```bash
git clone https://github.com/gourxb-28/webpage-summarizer-extension.git
cd webpage-summarizer-extension
```

### 2. Set up the backend

```bash
cd backend
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Pull the LLM

```bash
ollama pull llama3.2
```

### 4. Run the FastAPI server

```bash
uvicorn main:app --reload --port 8000
```

### 5. Load the Chrome Extension

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `extension/` folder from this repo
